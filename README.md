# TeamBilling

Plataforma SaaS de billing multi-organização com Django REST, Next.js, PostgreSQL e Stripe mock. Inclui autenticação, planos, assinaturas e gestão de equipes.

## Executar

```bash
docker compose up --build
```

Acesse `http://localhost:3000` e a API em `http://localhost:8000/api/docs/`.
